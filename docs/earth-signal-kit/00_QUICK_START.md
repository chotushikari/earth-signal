# Quick Start for Codex

## Session 1 — Understand before coding

Paste `CODEX_MASTER_PROMPT.md` into Codex. Ask it to execute Step 01 only. It must inspect the actual repository, verify the source baseline, identify the app's current branch/build/dependencies and return a risk-ranked migration plan. No API integrations or destructive changes in this session.

## Session 2 — Approve the plan

Review the audit. Confirm whether to keep React/Vite for the current hackathon iteration (recommended) or migrate frameworks. Review the first API proposals. Do not give the agent secrets in chat.

## Session 3 — Prove the science path

Execute Steps 02–15 in order, stopping for approval gates. Prioritize one verified SME2 vertical slice. Record actual Harmony output size, CPU time, peak RAM and raster metadata.

## Session 4 — Build the discovery experience

Execute Steps 16–24. Build the topic discovery home, place search/AOI selection, readiness report, investigation workspace, map and evidence UI.

## Session 5 — Reliability and release

Execute Steps 25–29. Add watchlists, reports, test security, provider terms, run a reproducible demo and write release notes.

## Interaction rule

Do not paste all prompts in one request. Codex should execute a single step, show evidence of completion, and wait. If a step needs an API, key, provider, cost, licence decision or destructive change, stop and ask before continuing.
