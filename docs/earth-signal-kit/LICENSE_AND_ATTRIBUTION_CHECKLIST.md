# Licence and Attribution Checklist

This file is a reminder, not legal advice. Codex must inspect current official provider terms and ask the user before adopting a provider whose terms/plan scope is unclear.

- NASA/NISAR: cite mission, product, granule IDs, DOI and source URLs. Distinguish NASA source data from our derived analysis.
- ASF/Earthdata/Harmony: comply with access terms, use authentication properly, do not overload services, and retain source provenance.
- OpenStreetMap: if approved, include attribution and comply with ODbL and tile-service usage policy; public tiles/Overpass are not bulk-download backends.
- WorldPop/FIRMS/DEM: check dataset-specific licences, attribution, resolution, year and permitted redistribution.
- Cesium ion: verify the Community plan's individual/personal/non-commercial scope against team/hackathon use; do not assume a team project qualifies.
- Esri/ArcGIS and CARTO: verify current terms and account requirements before public deployment; no assumption of unlimited free tile access.
- Open-source packages: record licences; review dependencies and security advisories.
- Third-party LLM: requires explicit approval, data/privacy review and cost/usage decision.

Add a provider credit in the app's About/Attribution view and in exported reports where required.
